# election-results

Live 2026 US election results on Cloudflare Workers (`election-results.classicminidiy.workers.dev`). Nuxt 4, Tailwind 4, d3-geo, civicAPI. Deploy with `bun run deploy`.

## Invariants

- **Neutrality.** The app never calls a race. Only civicAPI's `winner` flag shows as "Called". Every other status is labelled as an estimate. No ratings, no "flip"/"hold" language.
- **Party colours are ours, not civicAPI's.** civicAPI assigns colours per candidate (a second Republican can be yellow). `toCandidate` overwrites them with `partyColor()` from `shared/utils/parties.ts`. The seat bar keeps Democratic left and Republican right at all times.
- **Status uses the statewide count only.** `inferRace` status ignores the county projection so the list and the race page always agree. The projection flip is shown as a separate note.
- **Remaining vote is anchored statewide.** Regions only decide where the remainder sits; regional estimates are scaled down to the statewide remainder, and regions under 5% reporting are not extrapolated.
- **One region type per race.** Alaska returns boroughs, house districts and a "State" row; Maine returns counties and townships. `toRegions` keeps one type (`REGION_TYPE_PREFERENCE`) to avoid double counting.
- **Majority and RCV rules** live in `shared/utils/rules.ts` (GA/LA runoff; AK all races, ME federal races RCV). Below 50% these states never show "Out of reach".
- **Seats not on the ballot** come from the static table in `shared/utils/officeholders.ts`, not from civicAPI's national summaries (their `seats` may change during the night). The table also drives the "current officeholders" map toggle.
- **`/api/race/:id` proxies only races on today's ballot** (so arbitrary ids cannot fill the isolate cache). In dev, past races are allowed — `5861` is the finished 2025 VA governor race, useful for testing with real numbers.
- **Stale data is labelled, and a copy beats an error.** Under 90 s old, a cached copy is served at once with a background refresh. From 90 s, a request waits at most 2 s for the refresh (`REFRESH_WAIT_MS`), then gets the copy with `stale: true`. Copies expire after 10 minutes; the race list after 24 hours. Every isolate and object starts with the bundled race list `server/data/race-seed.json` (rebuild with `bun scripts/build-race-seed.ts` before a deploy), because a deploy starts a new object with an empty cache. On 2026-11-03 a deploy during a civicAPI outage returned errors until this existed. Without civicAPI a race page falls back to the list's counts after 3 s, with no county map. `FORWARD_TIMEOUT_MS` (7 s) covers a race page's 2 s + 3 s + 1.5 s. The UI shows the data's age from `dataAsOf`, not the poll time.

- **State feeds are a cross-check, never averaged.** Adapters: Clarity ENR in `server/utils/stateFeeds.ts` (CO 127407, IA 127077), the rest in `server/feeds/`, listed in `ADAPTERS`. Files for AK, HI, ND and RI exist but are not registered: none has run on tonight's data. No usable source or blocked on 2026-11-03: AL, AZ, IL, KS, KY, MA, ME, MI, MN, MS, MT, NH, NJ, NV, NY, OK, TN, TX, WI, WV, WY. Never work around a block. `mergeFeed` (`shared/utils/crossCheck.ts`) swaps in the state's counts only when candidates match by last name and the state has counted more votes. Reporting % always stays civicAPI's (a feed's units are counties/precincts/localities, not vote share). A failing feed is skipped and retried after 60 s.
- **Feed versions never go backwards.** Each adapter returns a version (Clarity `current_ver`, Tally `versionID`, VA `asOf`); OH and DE have none, so total votes stand in. A load whose version is not higher is ignored.
- **County data follows the counts.** When a race shows the state's counts and the feed has a county breakdown (Clarity `json/details.json`, Tally `locations`), the race page uses the state's counties (`regionSource: 'state'`), with names/FIPS filled in from civicAPI. A state county's % is precincts fully reported.
- **Vote-type splits are the state's, shown as-is.** VA (`/data/ballot-item/{id}`), DE (Socrata `machine/early/absentee_votes` columns) and AR (Tally `GetSingleContestResults`, names from `GetElectionInfo` → `voteTypes`) split a race's count by vote type. `server/utils/voteTypes.ts` shows a split only when `crossCheck.matched`, lines rows up by candidate name (`alignByName`, null on any missing name), caches each contest 60 s and waits at most 1.5 s. MO and OH publish no split. CO/IA Clarity `json/vt.json` is empty before counting; its shape is unverified. Do not use Tally's `FullDataFile.json` (50 MB) in the Worker.
- **One shared snapshot.** Nitro preset `cloudflare_durable`: `/api/*` forwards to one Durable Object running the same app (`server/utils/snapshot.ts`), so upstream caches are shared and an alarm refreshes every 15 s while people read. SSR has no cloudflare context; `viaSnapshot` uses `globalThis.__env__.$DurableObject`. If the object is unreachable, the isolate answers itself. The object name includes the Worker version (`CF_VERSION_METADATA`): a busy object kept running the old code after a deploy (2026-11-03), so each deploy uses a new object.
- **Territories are listed, never mapped or counted.** civicAPI types DC/GU/MP/AS/VI House delegates `Delegate`; `kindOf` maps them to `house` and `toSummary` sets `delegate: true`. They list under "DC and territory delegates" on the House tab and never count toward the 435 seats. GU/MP/VI governors list under "Territories" on the Governor tab and never count toward the 50. Runoff rules in `rules.ts` are per office: governors GU/VI/MP and delegates GU/VI/AS need a majority; the MP and DC delegates are plurality. Forecast seat totals skip territory keys. Puerto Rico has no federal or governor race until 2028.
- **Poll-closing times come from `shared/utils/pollClosings.ts`, never civicAPI's `polls_close`** (wrong for DE, CO, NV, WA, HI on 2026-11-03).
- **2024 baseline is a second opinion only.** `shared/utils/baseline.ts` (data `public/data/county-2024.json`, built by `scripts/build-county-2024.ts`) gives a turnout-based votes-left estimate and a county shift vs the 2024 presidential margin. Neither changes a status. Statewide races only.
- **Archive mode.** `bun scripts/archive.ts` then `ARCHIVE=1 bun run deploy`: pages read `public/archive/*.json` in the browser and stop polling. A plain `bun run deploy` is always the live site.
- **Runoffs and certification.** `RUNOFF_DATES` in `shared/utils/rules.ts` (GA 1 Dec all races, LA 12 Dec House only — LA House was an open primary on 3 Nov after the 2026 redistricting). `shared/utils/certification.ts` is edited by hand as states certify.
- **The forecast lives only on `/forecast`.** The Results/Forecast switch (`app/components/ModeSwitch.vue`) sits above the chamber tabs on both pages and keeps `?view=`. `/api/forecast` passes civicAPI's `/forecast/{senate,house,governor}/2026/civicapi` race figures through unchanged. No results page, status, colour or seat bar reads it. Its `*_pct` fields are win chances, not vote shares.
- **Forecast seat totals follow civicAPI's site, not its API.** `parseForecast` adds the seats not up (`officeholders.ts`) to the races counted by rating, which is what civicAPI's own site shows. The API's `totals` can disagree (Senate on 2026-11-03: D 62 · 5 · R 59 = 126) and are shown only as a note. When the simulation cannot all be true (both majority chances 100%, medians or expected seats over the chamber size), `simulationIssues` lists why and the page hides the majority chances, seat ranges and distribution. The figures are never corrected.
- **Map contrast.** `--map-line` outlines every state and county at ≥3:1 against `--panel` (WCAG 1.4.11). Hawaii has a bounding-box hit area; small states also get buttons under the map.

## Gotchas

- Clarity's CloudFront returns 403 to curl's default User-Agent. The descriptive UA in `cachedGet` is accepted. Do not switch to a browser UA.

- **Write exported object literals on several lines.** Nuxt's export scan (mlly) reads a comma in a one-line `export const A: T = { a: 1, b: 2 }` as a multi-variable declaration and swallows the next export, which then does not auto-import. A template reads the missing name as `_ctx.X` ("Cannot read properties of undefined"); a script gets "X is not defined". On 2026-11-03 `NO_RULES` swallowed `STATUS_LABEL`, and `/` returned a 500 at the first Senate vote, because the use in `index.vue` runs only on a race with votes in a Senate or governor tab. `tests/autoImports.test.ts` compares the scan with the source.
- `bun run build` while `nuxt dev` runs corrupts the dev server's auto-imports; restart dev after a build.
- `vue-tsc` does not run against the installed TypeScript version; `nuxt typecheck` fails. Rely on `bun run build`, `bun run test` and a browser check.
- civicAPI attribution is required (footer link).
- Tally ENR spells the write-in list `writeInChoices` on contests and `writeinChoices` on locations.
- Election night: `bun scripts/watch.ts` checks data age and every state feed; exit 1 means look.
